# Clash export: enable X25519MLKEM768 for REALITY

## Rationale

mihomo's `reality-opts.support-x25519mlkem768` enables X25519-MLKEM768 key
exchange (https://wiki.metacubex.one/en/config/proxies/tls/#reality-optssupport-x25519mlkem768).
Requested: emit it as `true` for every REALITY node.

## Decisions

- In the VLESS Clash export, set `reality-opts.support-x25519mlkem768: true`
  whenever `public-key` is written (REALITY nodes only).
- Always on, with no per-node or global switch. Older mihomo versions ignore
  unknown keys.

## Impact

Every VLESS REALITY node in Clash output gains the key. Non-REALITY VLESS
nodes and other types are unchanged.

## Verification

Rebuilt and requested `/sub?target=clash&list=true`:

- `vless://...?security=reality&pbk=...&sid=...` →
  `reality-opts: {public-key: ..., support-x25519mlkem768: true, short-id: "..."}`
- `vless://...?security=tls` → no `reality-opts`
